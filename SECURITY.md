# Reporting a security concern

[Open a private vulnerability report on GitHub](https://github.com/NeuroAssistants/NeuroSwarm/security/advisories/new). Sign in to GitHub and select **Report a vulnerability** from the repository's Security tab if you enter through the repository home page. Repository maintainers can follow up in the private advisory.

Include the affected commit, observer version and operating system, the impact you observed, and the smallest steps needed to reproduce it with synthetic data. Omit real credentials, customer files and session transcripts. Keep sensitive details in the private report.

## Version information

Development and fixes land on `main`. Report the commit you installed even if it predates the latest changes. This project does not currently publish a maintenance or backport schedule for older revisions.
