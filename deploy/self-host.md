# Install the console

From the repository root, run:

```sh
docker compose up --build -d
```

Open http://localhost:8790. For a new installation, retrieve the bootstrap password in your own terminal with `docker compose exec console cat /data/initial-password`. Protect access to Docker and the state volume. The initial account defaults to admin. Use the enrollment screen to generate a host-specific installer command. A remote host needs a reachable HTTPS address.

For HTTPS, point your DNS name at the server, allow inbound TCP ports 80 and 443, and set SWARMCONTROL_PUBLIC_URL to the complete public HTTPS origin before running:

```sh
docker compose -f compose.yaml -f compose.https.yaml up --build -d
```

Caddy handles certificates and forwards requests to the console. The console's direct port is bound to loopback. Run one application instance per state volume. SQLite and the threaded HTTP application still require load testing before setting a supported concurrency limit.

## Account registration

To close public workspace registration, set `SWARMCONTROL_REGISTRATION=closed` in the environment of the console before starting it. With Compose, put the setting in a local `.env` beside `compose.yaml` and run `docker compose up -d` to apply the change. Existing users can sign in, and administrators can invite members. The default is `open`.

For a source checkout, keep databases, backups, observer queues and bootstrap passwords in a private state directory outside the checkout. Git and Docker ignore the files generated by the default setup.

## Backup and recovery

The backup service uses the SQLite online backup API and checks each copy with integrity_check. It keeps seven daily database snapshots in the backups volume. Copy snapshots to protected off-host storage for recovery from host loss. Database snapshots contain private customer data. Each snapshot includes the primary database, the sibling swarmcontrol.db.tenants directory of tenant databases, and the local session.key when present. Back up deployment configuration, externally supplied secrets, and TLS keys separately. For a coordinated restore across multiple databases, stop writers before taking the snapshot.

To restore a selected snapshot on a machine with Python 3.12, use a new destination directory and inspect the restored instance before switching traffic. Replace the example paths:

```sh
python3 deploy/backup.py restore /secure/backups/SELECTED-SNAPSHOT /srv/swarm-restored
SWARMCONTROL_STATE_DIR=/srv/swarm-restored SWARMCONTROL_PORT=8791 python3 deploy/start_console.py
```

The normal startup command for a repository install is `SWARMCONTROL_STATE_DIR=/path/to/private/state python3 deploy/start_console.py`. Use an account with write permission to that directory. OpenBot is an optional integration.
