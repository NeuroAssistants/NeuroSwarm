# NeuroSwarm interface

The public introduction opens for visitors at the root. Signed-in operators keep their dashboard and can open the product introduction from the NeuroSwarm wordmark. The direct introduction link is `/?view=home`. Invitations and authenticated deep links retain their destinations.

| Surface reviewed | Design decision |
| --- | --- |
| Public introduction and installation | A folded copper sculpture made for this project leads the composition. A three-step example connects an edit to its test and result. The download and installation guide are adjacent to the Compose command. |
| Sign-in, organization creation and invitations | Keep the existing forms and validation together, with a direct jump to workspace access. |
| Dashboard, administration and onboarding | Warm stock, dark rules and a copper corner identify working panels. Serif headings carry hierarchy. Tabular numbers and the existing severity colors retain their meanings. |
| Activity map and line evidence | Preserve the graph and its relationships. A copper edge marks expansion and focus. The evidence remains readable as selectable text. |
| Live Events and detail | The explorer reads like an index. Typographic column headers, a selection rule and a framed inspector distinguish filters, records and evidence. |
| Attention and reproducible cases | Preserve the bounded lists, resolution states, diff colors and exact event links. |
| Small screens and motion | The hero folds into a single column. A brief entrance and focus or hover transitions leave static content visible. Reduced-motion mode disables the entrance and smooth scrolling. |

The home illustration is an original rendered set of folded copper fins. It is served locally. The Baked Design reference informed the use of material and scale; its graphics and fonts are not shipped. Browser screenshots of operational screens use synthetic records.
